# Linked Data Graph Prototype

An experiment with a graph representation of data objects of varying sizes.

## Installation

1. Clone repo
2. In repo directory, run `npm install`
3. Run `npm run dev` to start local server

## Usage

Enter a valid URL from the Getty Museum Collection API, which should begin with `https://data.getty.edu/museum/collection/`, for example: [https://data.getty.edu/museum/collection/person/d540519b-9937-4423-803e-00d096075859](https://data.getty.edu/museum/collection/person/d540519b-9937-4423-803e-00d096075859).
